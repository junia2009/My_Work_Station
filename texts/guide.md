# このポータルの使い方

## できること

仕事で使う**ツール**と**テキスト**（手順書・資料など）を置いておく作業台です。

- **ツール**：差分比較・正規表現テスト・メモなど、ブラウザの中だけで動く道具
- **テキスト**：Markdown で書いた資料を、目次つきで読める
- **検索**：ホームの検索バーから、ツールの名前やテキストの本文まで横断して探せる

> [!TIP]
> よく使うツールは、見出しの上の **☆ お気に入りに追加** で登録しておくと、メニューの上の方（スマホでは ★）からすぐ開けます。

## データの保存場所

入力した内容は、すべて**このブラウザの中だけ**で処理されます。外部のサーバーには送信されません。

| 種類 | 保存される場所 | 消えるとき |
| --- | --- | --- |
| ツールに入力した文字 | 保存しない | ページを閉じたとき |
| メモ | ブラウザ（localStorage） | ブラウザのデータを消したとき |
| お気に入り・テーマ | ブラウザ（localStorage） | ブラウザのデータを消したとき |
| テキスト | ポータル本体（`texts/`） | 消えない（リポジトリにある） |

> [!WARNING]
> メモはこのブラウザにしか保存されません。別の PC やブラウザでは見えません。大事なメモは、メモのページの「書き出し」で JSON に保存しておきましょう。

## オフラインで使う

一度開けば、ネットワークがなくても全部のツールとテキストが動きます。

- **PC（Chrome / Edge）**：右上の「INSTALL」ボタン、またはアドレスバーのインストールアイコンで、アプリとしてインストールできます
- **スマホ**：ブラウザのメニューから「ホーム画面に追加」

新しいバージョンを公開すると、画面下に「新しいバージョンがあります」と出ます。「更新する」を押すと切り替わります。

## 画面の操作

- 右上の **☾ / ☀** で明るさ、**CYAN / CRIMSON / EMERALD** で色を切り替えます
- 各ツールの「使い方・こんなときに使う」パネルの **▶ 例を試す** で、すぐに動きを確かめられます
- 画面を飛んでいる **PALLAS** は案内役です。タップするとヒントやツアー、吹き出しの「隠れる」でしまえます
- キーボードだけでも操作できます（最初の Tab で「本文へ移動」が出ます）

## ツールやテキストを増やす

自分で作ったツールや資料も、ここに置けます。手順は [ツール・テキストの追加方法](howto-add.md) を見てください。
