# Markdown 早見表

## 見出しと段落

```markdown
# 題名（ファイルの 1 行目に 1 つだけ）
## 章の見出し（ここで章のカードと目次が分かれる）
### 小見出し

段落は空行で区切ります。
行末に空白を 2 つ置くか \ を書くと、段落の中で改行します。
```

> [!NOTE]
> 改行しただけの行は、前の行とつながって 1 つの段落になります。日本語の文章では、つなぎ目に余計な空白は入りません。

## 文字の装飾

| 書き方 | 表示 |
| --- | --- |
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `~~取り消し~~` | ~~取り消し~~ |
| `` `コード` `` | `コード`（クリックでコピー） |
| `[リンク](https://example.com)` | [リンク](https://example.com) |
| `[別のテキスト](guide.md)` | [別のテキスト](guide.md) |
| `<https://example.com>` | <https://example.com> |

## 箇条書き

```markdown
- 項目
- 項目
  - 2 つ空白を入れると入れ子
1. 番号付き
2. 番号付き
- [ ] まだのこと
- [x] 済んだこと
```

- 項目
  - 入れ子
1. 番号付き
2. 番号付き

- [ ] まだのこと
- [x] 済んだこと

## コード

バッククォート 3 つで囲みます。言語名の後ろに、見出しに出すタイトルも書けます。右上の「コピー」でコピーできます。

````markdown
```bash 再起動の手順
sudo systemctl restart nginx
```
````

```bash 再起動の手順
sudo systemctl restart nginx
```

## 表

```markdown
| 項目 | 担当 | 期限 |
| --- | :---: | ---: |
| 見積もり | 佐藤 | 11/10 |
```

| 項目 | 担当 | 期限 |
| --- | :---: | ---: |
| 見積もり | 佐藤 | 11/10 |

`:---:` で中央、`---:` で右寄せになります。

## 囲み・引用

```markdown
> [!NOTE]
> 補足

> [!TIP] 題名も付けられる
> ちょっとしたコツ

> [!WARNING]
> 注意してほしいこと

> ふつうの引用
```

> [!NOTE]
> 補足

> [!TIP] 題名も付けられる
> ちょっとしたコツ

> [!WARNING]
> 注意してほしいこと

> ふつうの引用

## 区切り線・画像

```markdown
---
![画面の説明](images/screen.png)
```

画像は `texts/` の中（例：`texts/images/`）に置きます。

> [!CAUTION]
> HTML のタグを書いても、文字としてそのまま表示されます（スクリプトなどは動きません）。
